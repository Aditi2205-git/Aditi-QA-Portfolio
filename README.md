# Aditi — QA Engineer / Software Testing Portfolio

A recruiter-facing 2026 portfolio focused on QA Engineer, Software Testing and Quality Engineering roles.

## Proof of Work
The `qa-evidence/` folder contains the actual QA artifacts used in the portfolio:

- `WeatherSphere_QA_Test_Cases_and_Bug_Report.xlsx` — 30 test cases + 3 documented bugs + execution data.
- `Tech_News_QA_Test_Cases.xlsx` — 30 Tech News test cases + test summary.
- `images/` — visual previews of the spreadsheets shown in the Proof of Work section.

## Projects
- WeatherSphere Pro — live application + GitHub + QA evidence.
- Tech News Dashboard — public GitHub repository + QA evidence. GitHub Pages deployment is prepared as the next deployment step; no unverified live URL is presented as active.

## Run locally
Open `index.html` in a browser.

## Deploy
This is a static HTML/CSS/JS site and can be published with GitHub Pages. GitHub Pages uses an `index.html` entry file and can publish from a repository/branch or an Actions workflow.


## Important: GitHub Pages upload
Do **not** upload this portfolio as a single ZIP file if you want the screenshots and Excel evidence to work on GitHub Pages. Extract the ZIP and upload the **contents of this folder** so that `index.html`, `style.css`, `script.js`, and the `qa-evidence/` folder are in the published repository. The XLSX files and image previews are referenced with relative paths.
